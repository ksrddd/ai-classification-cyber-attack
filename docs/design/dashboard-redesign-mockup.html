Every field the dashboard reads, whether it is required, and exactly what renders when it is missing. Nothing here is aspirational — each “absent” behaviour is demonstrable by switching the active run in the rail.

metrics.json — run level

Read once per bundle

FieldNeedIf absent, the UI shows
run_namerequiredBundle is rejected; the no-bundle state is shown
class_namesrequiredBundle is rejected
models[]requiredBundle is rejected
per_class_n_testrequiredReliability flags cannot be computed
split_protocoloptionalnot recorded in the rail, and the split caveat is suppressed rather than guessed
n_calibrationoptionalCalibration row disappears; a note says the threshold was not tuned on a held-out split
data_fingerprintoptionalnot recorded — and a warning that this run cannot be tied to an input
duration_secondsnice to haveOmitted from the rail
majority_baseline_accnice to haveLift comparison is hidden, not shown as zero

metrics.json — per model

Every one of these is null in at least one existing bundle

FieldNeedIf absent, the UI shows
f1_macrorequiredModel is listed but unranked, with a reason
cv_f1_macro_stdoptionalnot recorded — never 0.0000, which would read as perfect stability
cv_f1_macro_scoresoptionalFold strip is replaced by a count of how many folds were recorded
label_shuffle_accoptionalLeakage panel says the check did not run for this model
target_thresholdoptionalThreshold row omitted; metrics are labelled as argmax rather than tuned
target_fproptionalBudget column shows not measured, and the model is excluded from champion selection
best_paramsnice to haveHyperparameter panel says defaults were used

The rule throughout: a missing measurement is rendered as missing. It is never substituted with zero, and never silently dropped from a ranking.

Files the API needs

Per bundle directory

results/<run_id>/
  metrics.json              required
  bundle_manifest.json      recommended — carries split_protocol
  <model>_per_class.csv     required for the per-class view
  <model>_metrics.json      optional
  <model>_confusion_matrix.png   optional
  report.md                 optional

Today the API reads results/metrics/, results/figures/ and results/shap/ — all three contain only a .gitkeep. That is why the live dashboard is empty regardless of which bundle exists.
