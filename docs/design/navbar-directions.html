The reframe all three directions share

This is not a product with users and sessions. It is the report of one training run. Once you accept that, the rail's job changes: carry the run's identity — the thing that decides whether the numbers can be trusted — and lay the nav out as the pipeline that produced it. That alone removes the logo, the shield, the session block and the abstract verb groups, because none of them survive the question "what does a reviewer need here?"

Three directions

What it does

The head is a typeset run record, not a logo lockup. A reviewer's first three questions — which run, which data, was it seeded — are answered before they click anything. The conditional chip sits next to the run name, so the caveat travels with every page rather than living only on Overview.

What it removes

  • Wordmark, shield, letter tile, session block, Settings — all of it
  • Group labels drop to sentence case at normal tracking: no eyebrows
  • Nav items carry what they contain, so the counts do work instead of decorating

Cost: no product identity at all. If you want the project to have a name on screen for the poster or the slide deck, this direction won't give you one.

B · Numbered pipeline index

the stages really are a sequence, so the numbers mean something
Triage CICIDS2017 · run latest
6 of 7 stages produced output

What it does

Numbered markers are usually a generated-design tell, but the ban has an exception and this hits it: your stages genuinely run in order, and the order is information a reviewer needs. The dot on the right is completion state — filled means this stage produced output, hollow means it was skipped. Explainability reads hollow, which is true.

What it removes

  • Icons entirely — the number is the anchor
  • Verb-noun groups; the sequence replaces the grouping
  • Session chrome, replaced by a real completion count

Cost: numbering only stays honest while the order is real. If you later add a page that doesn't belong to the pipeline, the whole device breaks and you're back to decoration.

gives the wide metric tables the full viewport

What it does

Drops the 216px rail. Your actual content is wide numeric tables — the comparison view is six columns and the per-class view is six more — so the rail was spending a fifth of the screen on seven links. The wordmark is set lowercase in mono as a path, triage/latest, so identity and run are one lockup and no logo is needed.

What it removes

  • The rail, and with it the collapse toggle and its state
  • Groups — five tabs don't need grouping
  • The icon set entirely

Cost: seven items is near the ceiling for tabs. You'd merge Model detail and Comparison into one "Models" view with a selector, which is a real content change, not just chrome.

On the name

Your call, not mine — but "CyberML" is the weakest part and it's cheap to change. Your README already has the better idea in it: "like a doctor diagnosing illness from symptoms … IDS tools detect that an attack happened; this system tells the operator what kind." That's triage. Three options, ordered by how much I'd argue for them:

Triage recommended

A real word for exactly what the system does: sort incoming cases by kind and urgency. Carries your own README metaphor. Not a compound, not a category label, and it survives being said out loud in a defence.

ids-9
descriptive

Nine-class intrusion detection, stated flatly. Reads as a lab designation rather than a product. Honest, forgettable, and impossible to accuse of marketing.

No name direction A

A thesis artefact doesn't need a startup name. The rail carries the run instead. This is the strongest anti-AI move available, and it costs you a title slide.
